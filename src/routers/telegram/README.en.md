# Creating a Telegram Bot

1. Create and edit your bot in the [BotFather](https://web.telegram.org/k/#@BotFather) chat
2. Save the generated token in your `mise.local.toml` file

# Finding Your User ID

1. Send "/start" to [User Info](https://web.telegram.org/k/#@userinfobot)
2. Save the ID shown in your `mise.local.toml` file
