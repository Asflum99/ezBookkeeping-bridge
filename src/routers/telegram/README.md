# Crear un bot en Telegram

1. Crea y edita tu bot en el chat de [BotFather](https://web.telegram.org/k/#@BotFather)
2. Guarda el token generado en tu archivo `mise.local.toml`

# Ubicar tu ID de usuario

1. Escribe "/start" en el chat de [User Info](https://web.telegram.org/k/#@userinfobot)
2. Guarda el ID que te muestre en el archivo `mise.local.toml`
